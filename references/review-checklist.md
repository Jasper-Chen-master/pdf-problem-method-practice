# Review Checklist

Use this checklist when extraction or classification is ambiguous.

1. Confirm the question starts and ends at the actual numbered boundary, not a section header, footer, or the next topic's notes.
2. Verify a separate answer-key item against both its number and its subject context before pairing it.
3. Confirm the source file and page range by reopening the original PDF when the extracted text is unclear.
4. Check that the chosen method is evidenced by solution steps, not an unrelated word appearing in nearby text.
5. Mark uncertain parsing and unmatched solutions in `unresolved.jsonl` instead of forcing a low-quality record.
